# Template Method Design Pattern

-> Bir üst sınıftaki bir algoritmanın iskeletini tanımlayan ancak alt sınıfların yapısını değiştirmeden algoritmanın belirli adımlarını geçersiz kılmasına izin veren behavioural tasarım desenidir.

-> Alt sınıfların genel yapısını değiştirmeden algoritmanın belirli bölümlerinin özelleştirilmesine olanak tanır.
